# COIL (Atari XL/XE)

A dynamic two-snake duel (player vs. CPU) for 8-bit Atari computers.

## Requirements
* Atari 800XL / 65XE / 130XE (or an emulator, e.g., Altirra)
* 64 KB RAM
* Joystick in Port 1

## Controls
* **Joystick (Port 1):** control the green snake
* **FIRE button:** start the game / restart after a round
* **START (on the console):** return to the title screen while saving your high score
